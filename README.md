# Subliminal Relay

A Figma plugin exclusive to the **Subliminal Design System**.

Allows designers to extract their customized Figma variables and styles (colors, typography, effects, etc.) as structured JSON — then push that output directly to a GitHub repository or download it manually.

---

## Features

- **GitHub Export** — Authenticate with a GitHub Personal Access Token and push your token JSON to any repo, branch, and file path of your choosing. Creates or updates the file with a timestamped commit.
- **Manual Export** — Extract tokens and download the JSON file or copy it to your clipboard, no GitHub connection needed.
- **Structured output** — Variables are exported following the [W3C Design Token format](https://design-tokens.github.io/community-group/format-spec/), nested by group path.

---

## Development

### Prerequisites

- Node.js 18+
- A Figma account with Developer Mode enabled

### Setup

```bash
npm install
```

### Build

```bash
# Development (watch mode)
npm run dev

# Production
npm run build
```

### Loading in Figma

1. Open Figma Desktop → **Plugins** → **Development** → **Import plugin from manifest…**
2. Select the `manifest.json` in this directory.
3. The plugin will appear under your development plugins.

> **Note:** Replace `REPLACE_WITH_FIGMA_PLUGIN_ID` in `manifest.json` with the ID generated by Figma when you create the plugin in the Figma developer portal.
